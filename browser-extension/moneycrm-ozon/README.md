# MoneyCRM Ozon Bridge

Локальный коннектор для личного использования MoneyCRM. Он не просит и не хранит банковский логин, код-пароль или SMS-коды. Вход выполняется только на официальном `finance.ozon.ru`, а коннектор использует уже открытую браузерную сессию и передаёт в MoneyCRM только текст строк истории операций.

## Установка один раз

1. Откройте Chrome → `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `browser-extension/moneycrm-ozon`.
5. Откройте MoneyCRM заново.

## Использование

1. MoneyCRM → Настройки → Банки и счета → Ozon Банк.
2. При первом запуске нажмите синхронизацию. Откроется официальный кабинет Ozon Банка.
3. Войдите там обычным способом. MoneyCRM не получает данные входа.
4. Вернитесь в MoneyCRM и нажмите **Синхронизировать** ещё раз.
5. После первого входа браузер обычно сохраняет сессию, поэтому дальнейшее обновление выполняется одной кнопкой, пока Ozon не попросит войти заново.

Если коннектор не находит операции автоматически, один раз откройте в Ozon историю/все операции и повторите синхронизацию. Коннектор оставляет вкладку Ozon открытой, поэтому следующие обновления становятся проще.

## Ограничение PWA на iPhone

Расширение работает в настольном Chromium-браузере. Обычная PWA на iPhone не может читать страницу другого банковского домена из-за защиты браузера. После синхронизации с компьютера данные сразу доступны в мобильной PWA через Supabase. Для прямой синхронизации на iPhone понадобится отдельный нативный коннектор, когда MoneyCRM будет собираться как iOS-приложение.
